# installer

A JumPHP desktop app: native windows whose pages are HTML / CSS / JS, driven by PHP (Tauri).

```bash
bin/jumphp app:run installer       # a window on your screen
bin/jumphp app:test installer      # lint + phpunit + the app for real on a virtual screen
bin/jumphp app:shot installer      # var/screenshots/app.png
bin/jumphp app:export installer    # dist/standalone/installer-linux-x86_64: the app for Linux, one file to give
```

See `docs/tauri.md` of JumPHP.
